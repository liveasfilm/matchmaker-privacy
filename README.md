# 수상한 결혼정보회사 — Privacy Policy

수상한 결혼정보회사 (Suspicious Matchmakers) 모바일 게임의 개인정보처리방침 공개 페이지입니다.
게임 소스 코드는 이 저장소에 포함되지 않습니다.

- 공개 URL: https://liveasfilm.github.io/matchmaker-privacy/
- 언어: 한국어 · English (한 페이지 내 탭 전환)
- 최종 수정일: 2026-09-13 (앱 1.0.0 — AdMob 배너·전면·보상형 + 인앱결제)

## 스토어 등록 시 사용

| 항목 | 값 |
|---|---|
| Google Play → 앱 콘텐츠 → 개인정보처리방침 URL | `https://liveasfilm.github.io/matchmaker-privacy/` |
| App Store Connect → 앱 정보 → 개인정보 보호 정책 URL | `https://liveasfilm.github.io/matchmaker-privacy/` |

## 수정 방법

`index.html` 한 파일만 수정하고 `main`에 push하면 GitHub Pages가 자동 재배포합니다.
새로운 데이터 처리(분석 SDK, 로그인, 온라인 기능 등)를 추가하면 1·3·4·5절과
Play 데이터 보안 양식, App Store App Privacy를 함께 갱신해야 합니다.
